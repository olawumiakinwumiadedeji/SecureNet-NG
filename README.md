# SecureNet-NG: Home Network Hardening and Security Assessment

## Project Overview

SecureNet-NG is a practical cybersecurity project that demonstrates how to design, assess, and harden a typical Nigerian home/office network. The project was developed as part of the 3MTT Knowledge Showcase to address common network security weaknesses through practical implementation and documentation.

## Problem Statement

Many Nigerian homes and small businesses use wireless networks with weak security configurations, default settings, and little awareness of cyber threats. These weaknesses expose users to unauthorized access, credential theft, malware infections, and data breaches.

## Project Objectives

- Design a secure home network.
- Configure a wireless router using WPA2-Personal security.
- Verify secure connectivity between devices.
- Perform a basic network assessment using Kali Linux.
- Provide practical hardening recommendations.

## Tools Used

- Cisco Packet Tracer
- Kali Linux
- Oracle VirtualBox
- Wireshark
- Nmap
- Linux Terminal

## Project Activities

### Network Design
- Built a realistic home network topology.
- Configured wireless connectivity.
- Enabled DHCP.
- Connected wireless clients.

### Security Configuration
- Configured WPA2-Personal authentication.
- Used a strong Pre-Shared Key (PSK).
- Verified successful wireless connection.

### Network Assessment
- Verified network interfaces.
- Tested connectivity using ping.
- Examined routing information.
- Demonstrated Nmap.
- Captured network traffic using Wireshark.

## Deliverables

- Packet Tracer Lab
- Assessment Report
- Wireshark Evidence
- Hardening Recommendations
- Demonstration Video

## Hardening Recommendations

- Change default router administrator credentials.
- Use WPA2/WPA3 encryption where supported.
- Disable WPS.
- Use strong passwords.
- Update router firmware regularly.
- Monitor connected devices.
- Segment guest devices from trusted devices.
- Educate users on safe network practices.
